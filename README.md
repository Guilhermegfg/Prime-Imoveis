# 🏠 Prime Imóveis

Landing page imobiliária criada como projeto demonstrativo da **GFGTech**, com foco em apresentação premium de imóveis e geração de contatos qualificados.

O projeto simula a presença digital de uma imobiliária/corretor em Goiânia, combinando **design sofisticado, filtros de imóveis, prova de valor e conversão via WhatsApp**.

## ✨ Destaques

- Design responsivo e mobile-first
- Hero section com imóvel em destaque
- Catálogo de imóveis
- Filtros por tipo, bairro e faixa de preço
- Cards com informações de cada imóvel
- Seção de bairros
- Apresentação do corretor
- CTAs direcionados para WhatsApp
- Animações e interações em JavaScript
- SEO local básico
- Layout pensado para geração de leads

## 📍 Região da demonstração

**Goiânia — Goiás**

O conteúdo apresenta imóveis fictícios em regiões como:

- Setor Marista
- Setor Bueno
- Jardim Goiás
- Jardins Munique
- Alphaville Flamboyant

## ▶️ Como executar

Clone o repositório e abra o arquivo `index.html` no navegador.

Também é possível utilizar um servidor local:

```bash
python -m http.server 8000
```

Depois acesse:

```
http://localhost:8000
```

## 🎯 Objetivo comercial

A estrutura foi pensada para ajudar uma imobiliária ou corretor a:

- apresentar imóveis com mais valor percebido;
- organizar a oferta por perfil do comprador;
- gerar contatos diretamente de cada imóvel;
- reforçar credibilidade e posicionamento;
- reduzir atrito até o primeiro atendimento.

## ⚠️ Demonstração

A **Prime Imóveis é uma marca fictícia** usada para portfólio. Imóveis, preços, corretor, números e demais informações comerciais são demonstrativos.
